School Agent v0.3.0 adds generated files, interactive website previews, compact navigation, account pictures and read-only student workspaces, plus fixes for response handling and workspace scrolling.

## New features

- **Generated files:** permitted users can request downloadable code/text files, edit syntax-coloured source, save versions and download from Files → Generated.
- **Website previews:** preview HTML/CSS/JavaScript beneath chat code or in the Files panel. Linked local assets are bundled within access/size limits. Pop previews into movable, resizable windows.
- **Code tools:** Copy and Download icons, sticky code headers and preview controls keep source available while viewing a result.
- **Compact sidebar:** collapsible icon rail, saved expanded width, quick hover labels and a recent-conversation fly-out. Chats returns to the last conversation; the logo opens Home.
- **Account controls:** separate profile account card, uploaded pictures/preset icons, and Settings grouped at the bottom of the compact profile menu.
- **Student workspaces:** authorised staff can select a student and review accessible chats/notes read-only from Staff studio. Staff retain their identity, existing roster boundaries and audit logging.
- **Reading controls:** per-account page/chat text sizes, consistent message typography, a centred jump-to-latest button and scrollbars that recede while idle at the latest message.
- **Response activity:** live public phase updates and actual stream-arrival counters, cancellable requests and sequential reveal of paragraphs/code. These are activity summaries, not private model reasoning.
- **Notes and Files:** shared folding cards, faster switching, top-aligned edge tabs and adjustable preview width.

## Fixes and reliability

- Saving a profile picture or account details keeps the chat position, unsent draft and mounted workspace.
- Opening an inline code preview keeps the source and chat scroll position in place.
- Latest corrections receive stronger priority; explicitly excluded code dependencies trigger one corrective retry, with incompatible code withheld if it still fails.
- Model-server connection failures return actionable errors instead of a generic processing failure.
- Course navigation remains scoped to the signed-in account; preview ownership and student/staff record boundaries remain enforced on the server.

## Included and verified

- Source code, editing documentation, demo screenshots and five public demo logins in `DEMO_LOGINS.txt`.
- **244 Python tests**, JavaScript syntax/format checks and isolated desktop/mobile browser checks. Browser checks cover picture uploads, scroll/draft preservation, previews, navigation and read-only review.
- Generated programs can still contain model errors. Browser JavaScript previews are sandboxed; optional Python/JavaScript container execution stays **off by default**. The isolated demo disables the host terminal and uses labelled sample replies.

## Upgrade

Stop the server, back up the private runtime directory (`.local/` or `SCHOOL_AGENT_STATE`), update the source and restart. Keep runtime data separate from the source; first startup creates the new avatar preference table automatically. Real accounts, chats, uploads, pictures, credentials and logs are excluded from the release source. Model downloads are separate; this release does not change the configured model or its memory settings.
